تجربة مشغّل الفيديو

اضغط تشغيل، جرّب شريط الوقت، أو افتح ملء الشاشة. العيّنة فيديو اختبار صامت مدته ست ثوانٍ، مضمّن في الملف ويشتغل محليًا من غير حساب أو اتصال بالسيرفر.

عيّنة فحص الحركة والألوانجاهز للتجربة · فيديو غير مشفّر

دي معاينة لعناصر التحكم الأصلية في المتصفح، وشكلها بيتغيّر بين الهاتف والكمبيوتر. مشغّل الدروس المحمية وواجهة الـSDK لسه ضمن المراحل الجاية.

النص معاينة لطريقة عرض الحالة. التجربة المحلية مستقلة عنها.

قرار الفرونت اليوم

اطلب إمكانيات إصدار التراخيص من خلال باك إند تطبيقك. المسار متاح بدون توكن. لما تكون القيم كلها false، اعرض حالة عدم توفر التشغيل المحمي قبل تحميل المشغّل.

GET /api/v1/license/capabilities
{"clearkey":false,"widevine":false,"fairplay":false}

ربط التطبيق بالنسخة الحالية

  1. المستخدم يسجّل الدخول في تطبيقك. باك إند التطبيق يربط حسابه بهوية OpenShield المخصّصة له ويفحص صلاحياته. احتفظ باعتماد الناشر وتوكن الإدارة على السيرفر.
  2. صفحة الناشر ترسل الملف إلى باك إند التطبيق. الباك إند يرسله كجسم طلب video/mp4 إلى POST /api/v1/content/:id/assets بجلسة الناشر. استخدم jobId من استجابة 202 لمتابعة GET /api/v1/jobs/:id بصلاحيات المالك.
  3. عند completed، اعرض «تم تجهيز الفيديو». مسارات outputs داخل مساحة تخزين خاصة. صفحة المشاهد تقدر تعرض عنوان المحتوى لو عنده استحقاق؛ الملفات الخاصة لا تُستخدم كرابط video.src.

المثال التالي يُنفَّذ داخل معالج HTTP في باك إند تطبيقك. عرّف مسارًا تابعًا لتطبيقك مثل /video/capabilities لتمرير النتيجة للواجهة. لو الباك إند على نفس مضيف Docker يقدر يستخدم عنوان loopback التالي.

const base = process.env.OPENSHIELD_URL ?? "http://127.0.0.1:18321";
const res = await fetch(base + "/api/v1/license/capabilities", {
  signal: AbortSignal.timeout(5000)
});
if (!res.ok) throw new Error("OpenShield discovery HTTP " + res.status);
const { clearkey, widevine, fairplay } = await res.json();
return { clearkey, widevine, fairplay };

خطأ الشبكة أو 404 معناه إن طلب الاستعلام فشل. اعرض حالة تعذّر الاتصال أو راجع إصدار السيرفر، وميّزها عن الرد الصحيح 200 بقيم false.

تشغيل درس محمي في المراحل القادمة

  1. قبل بدء التشغيل، يتحقق الباك إند من استحقاق المشاهد والجهاز ويصدر جلسة تشغيل قصيرة مرتبطة بالمحتوى. واجهة هذه الجلسة لسه قيد التخطيط.
  2. يستلم المتصفح رابط بيان DASH/HLS مسموحًا له بقراءته وإعدادات مزوّد ترخيص مدعوم. التوافق يعتمد على نظام الحماية والمتصفح والجهاز.
  3. يربط تطبيق الويب عنصر <video> بمكتبة مثل Shaka Player. يستخدم اتصال HTTPS ويرسل توكن التشغيل في طلب الترخيص إلى وجهة المزوّد المعتمدة فقط. عند انتهاء الجلسة يتوقف التشغيل أو يطلب تجديدها من الباك إند.

التحقق من الاستحقاق وقت الترخيص، وتقديم المقاطع للمشاهد، واختبار التشغيل المحمي على الأجهزة، خطوات لازمة قبل تشغيل هذا المسار فعليًا. مفتاح تغليف السيرفر MEDIA_KEK مكانه داخل خدمة المعالجة.
